Reflow Oven Controller

CV-8052 Microcontroller • Assembly 8052 • K-Type Thermocouple • Solid-State Relay (SSR) • Python Telemetry

The Reflow Oven Controller is an embedded system designed to solder surface-mount devices (SMDs) onto printed circuit boards. Built around a CV-8052 microcontroller, the system regulates a 1500 W toaster oven to execute a multi-stage thermal profile while enforcing strict safety constraints.

Hardware Design
  • Temperature Sensing: Utilizes a K-type thermocouple amplified by an op-amp circuit feeding voltage to the microcontroller's ADC.
  • Thermal Control: A solid-state relay (SSR) receives pulse-width modulation (PWM) signals to regulate average oven power.
  • User Interface: Includes an LCD, a keypad, switches, and a 7-segment display for temperature readouts.
  • Safety Sensing: Incorporates an onboard accelerometer to detect physical disturbances or tipping.
Software Design (Assembly)
  • Interrupt-Driven Scheduler: A 1 ms hardware timer manages PWM generation, time tracking, and display updates without blocking the control loop.
  • Finite State Machine (FSM): Orchestrates the reflow cycle through six states: idle, preheat, soak, reflow ramp, hold, cool, and error.
  • Digital Filtering: Averages multiple ADC readings to mitigate electrical noise before calculating temperature.
  • Non-Blocking Audio: Uses an independent timer to generate audible feedback without freezing control logic.
Key Features & Telemetry
  • Accuracy: Maintains temperature tolerance with a maximum error of 2.998°C across the 22°C to 240°C range.
  • Safety Aborts: Automatically disables heating if the oven is tilted, manually stopped, or fails to reach 50°C within 60 seconds.
  • Telemetry Dashboard & Reporting: Streams serial data to a Python web interface displaying a real-time plot of the reflow curve, and automatically generates and emails a PDF run report upon cycle completion.

Line-Following / Field-Tracking RC Car

EFM8 • STM32 • PIC32 • Bare-Metal C • Inductive Sensor Array • VL53L0X ToF • IR Communication

The Field Tracking Robot is an embedded system capable of manual and autonomous navigation. The vehicle detects and follows magnetic fields generated by an energized guide wire, executes pre-programmed path decisions at intersections, and responds to infrared (IR) remote commands.

Hardware Design
  • Processing: An EFM8 microcontroller drives the robot, an STM32 microcontroller manages the remote controller, and a PIC32 microcontroller controls a servo-based lifting mechanism on the RC car.
  • Sensors: Three inductive coils, amplified by op-amps, detect the magnetic guide wire. A VL53L0X Time-of-Flight (ToF) sensor measures obstacle distance over I2C.
  • Actuation: Discrete MOSFET-based H-bridges drive bidirectional motor movement.
  • Communication: A MOSFET-driven IR LED transmits 38 kHz modulated signals from the remote.
Software Design (Bare-Metal C)
  • Control Logic: A finite state machine (FSM) maps movement states to pulse-width modulation (PWM) outputs for motor control.
  • Navigation: A threshold-based algorithm compares left and right inductor ADC readings to maintain wire alignment. The middle inductor triggers intersection path sequences.
  • Speed Regulation: A Proportional-Integral-Derivative (PID) controller dynamically adjusts motor PWM based on ToF sensor data to maintain a target 100 mm following distance.
  • Communication: Timer interrupts generate PWM for IR transmission, while UART decoding translates received commands.
Features
  • Navigation Modes: Operates in manual remote-control mode or autonomous guide-wire tracking mode with intersection path selection.
  • Cruise Control & Safety: PID cruise control maintaining a 100 mm buffer from obstacles; supports forward, reverse, pivot, and fine-grained adjustments.
  • Feedback & Terrain: Battery voltage monitoring LEDs, directional blinkers, audio alerts, and an isolated servo mechanism to traverse uneven surfaces.

Multi-Protocol Digital Logic Analyzer

Intel DE10-Lite FPGA (MAX 10) • SystemVerilog • QuestaSim • SPI • I2C • UART • Python

The Logic Analyzer is a hardware tool built on the Intel DE10-Lite FPGA to capture and decode SPI, I2C, and UART serial communication protocols. The system processes incoming signals, buffers the data, and transmits it to a host PC for monitoring and analysis.

Design & Architecture
  • Processing Platform: Synthesized on the Intel DE10-Lite FPGA board.
  • Signal Source & Validation: Tested and validated using an ESP32 microcontroller to generate SPI, I2C, and UART test signals.
  • State Machines & Oversampling: SystemVerilog finite state machines (FSMs) utilize 16x oversampling to decode incoming serial data streams reliably.
  • Data Management: A hardware FIFO buffer stores decoded data packets to prevent data loss prior to transmission across asynchronous clock domains.
  • Verification: Hardware modules were simulated, timing-verified, and debugged using QuestaSim.
Features & Telemetry
  • Multi-Protocol Decoding: Configurable hardware decoding for SPI, I2C, and UART protocols.
  • User Interface: 7-segment displays provide real-time visual indication of the active protocols and decoded data.
  • PC Telemetry: A Python script reads the serial data via UART and parses communication packets for terminal display.

On Catastrophic Forgetting in Low-Rank Decomposition-Based PEFT

Research Paper • arXiv: 2603.09684 • Vision Transformers (ViT) • LoRA • PiSSA • LoRETTA • WeGeFT

Muhammad Ahmad, Jingjing Zheng, Yankai Cao (University of British Columbia).

Developed in collaboration with a PhD student, this research paper investigates catastrophic forgetting in low-rank decomposition-based Parameter-Efficient Fine-Tuning (PEFT) methods under continual learning settings. It explores how constraining model updates to low-dimensional subspaces influences task interference and knowledge retention across sequential computer vision tasks.

Methodology & Experimental Setup
  • Model Architecture: Utilizes Vision Transformers (ViT-Base and ViT-Large) pretrained on ImageNet-1K as the base backbones.
  • Fine-Tuning Framework: Evaluates Full Fine-Tuning against four PEFT strategies: LoRA, PiSSA, LoRETTA, and WeGeFT implemented via Hugging Face.
  • Execution & Automation: Evaluated across sequential vision tasks (CUB-200-2011, EuroSAT, Intel Image Classification, and Sports Image Classification) using automated Python and Bash execution pipelines.
  • Evaluation Metrics: Assesses performance via Chaudhry's average forgetting metric, per-task accuracy, and final average accuracy across sequential tasks.
Key Findings
  • Matrix Rank Trade-offs: Standard LoRA exhibits higher forgetting at small ranks due to forced shared directions, whereas higher ranks steadily decrease forgetting.
  • Principal Subspace Interference: PiSSA causes significant forgetting at low ranks by directly updating the principal singular vectors encoding shared representations.
  • Structural Alignment & Tensor Benefits: Structurally aligned methods (WeGeFT) and tensor-train decompositions (LoRETTA) minimize forgetting with minimal parameter budgets.
