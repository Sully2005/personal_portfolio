Reflow Oven Controller

CV-8052 Microcontroller Assembly 8052 K-Type Thermocouple SSR PWM Control Python Telemetry Op-Amp Signal Conditioning
±2.998°C Max Temperature Error
1500 W Oven Power Regulated

The Reflow Oven Controller is an embedded system designed to solder surface-mount devices (SMDs) onto printed circuit boards. Built around a CV-8052 microcontroller, the system regulates a 1500 W toaster oven to execute a multi-stage thermal profile while enforcing rigorous hardware safety constraints.

Hardware Design & Architecture
  • •
    Temperature Sensing: Utilizes a K-type thermocouple amplified by an analog op-amp conditioning circuit feeding voltage directly to the microcontroller's ADC.
  • •
    Thermal Power Control: A solid-state relay (SSR) receives pulse-width modulation (PWM) signals to regulate average oven heating power.
  • •
    User Interface: Integrated 16x2 LCD, 4x4 matrix keypad, control switches, and a 7-segment display for immediate real-time temperature readouts.
  • •
    Safety Sensing: Onboard accelerometer detects physical disturbances, bumps, or oven tipping to prevent hazards.
Firmware & Software Architecture (Assembly)
  • •
    Interrupt-Driven Scheduler: 1 ms hardware timer manages PWM signal generation, elapsed time tracking, and display refreshes without blocking the main control loop.
  • •
    Finite State Machine (FSM): Orchestrates the full reflow cycle across 6 discrete states: Idle, Preheat, Soak, Reflow Ramp, Hold, Cool, and Error.
  • •
    Digital Noise Filtering: Multi-sample averaging filter smooths ADC raw telemetry to mitigate electrical noise prior to temperature calculations.
  • •
    Safety Aborts: Automatic hardware disable if the oven tilts, is manually aborted, or fails to cross 50°C within 60 seconds.
  • •
    Telemetry & Reporting: Streams real-time serial telemetry to a Python web interface plotting the reflow curve, with automated post-cycle PDF report generation emailed to the user.

Magnetic Field-Controlled Autonomous RC Car

STM32 PIC32 EFM8 Inductor Array Sensing VL53L0X ToF (I2C) PID Cruise Control Discrete H-Bridges 38kHz IR Remote
100 mm Target Obstacle Buffer
3 MCUs Distributed Processing

The Field Tracking Robot is an embedded robotic platform capable of both manual infrared (IR) remote navigation and autonomous electromagnetic guide-wire tracking. The vehicle dynamically detects magnetic fields radiated by energized guide wires, executes programmed path decisions at wire intersections, and enforces automatic collision mitigation.

Distributed Hardware Architecture
  • •
    Multi-MCU Processing: An EFM8 drives motor logic and inductive navigation; an STM32 processes joystick inputs on the remote controller; a PIC32 controls an isolated servo lifting mechanism.
  • •
    Magnetic Sensors: 3 tuned inductive coils with op-amp signal conditioning detect guide-wire magnetic fields for differential steering.
  • •
    Distance Sensing: VL53L0X Time-of-Flight (ToF) laser sensor interfaced over I2C for millimetric obstacle detection.
  • •
    Actuation & Comms: Discrete MOSFET-based H-bridges drive bidirectional DC motors; MOSFET-driven IR LED transmits 38 kHz modulated command packets.
Bare-Metal Firmware Architecture (C)
  • •
    Movement FSM: State machine translates locomotion states into high-resolution PWM duty cycles for bidirectional motor control.
  • •
    Threshold Navigation: Compares left and right inductor ADC voltages to maintain precise center-wire alignment; middle inductor triggers intersection path branches.
  • •
    PID Cruise Control: Proportional-Integral-Derivative control loop dynamically modulates motor PWM based on ToF telemetry to maintain a constant 100 mm trailing distance.
  • •
    Feedback & Safety: Hardware battery voltage monitoring LEDs, directional turn blinkers, audio alerts, and terrain servo traversal.

Multi-Protocol Digital Logic Analyzer

Intel MAX 10 FPGA (DE10-Lite) SystemVerilog QuestaSim SPI / I2C / UART Asynchronous FIFO 16x Oversampling ESP32 Testbench Python Telemetry
16x Sampling Resolution
3 Protocols SPI, I2C & UART

The Logic Analyzer is a dedicated hardware measurement instrument synthesized on the Intel MAX 10 (DE10-Lite) FPGA to capture, buffer, and decode high-speed SPI, I2C, and UART serial communication streams. Synthesized hardware modules handle asynchronous clock-domain crossings and transmit parsed telemetry to a host workstation.

Hardware & Digital Architecture
  • •
    FPGA Platform: Synthesized on the Intel Altera MAX 10 (DE10-Lite) FPGA board.
  • •
    Signal Generator Testbench: Built an ESP32 hardware harness to inject known SPI, I2C, and UART waveforms for hardware validation.
  • •
    State Machines & Oversampling: SystemVerilog FSMs implement 16x oversampling clock generators to capture noisy, jittery incoming asynchronous serial signals reliably.
  • •
    Memory Architecture: Implemented hardware FIFO buffers to capture and queue decoded protocol frames across asynchronous clock domains without data drops.
Verification & PC Telemetry
  • •
    QuestaSim Testbenches: Verified and debugged complex edge cases, frame timing, and parity checks in simulation prior to hardware synthesis.
  • •
    On-Board Visualization: 7-segment displays show active decoded protocol identifiers and live data byte readouts.
  • •
    Python PC Telemetry: Custom Python script reads serial streams via UART, parsing and printing structured communication packets in real time.

On Catastrophic Forgetting in Low-Rank Decomposition-Based PEFT

Vision Transformers (ViT) LoRA / PiSSA / LoRETTA / WeGeFT Continual Learning Hugging Face PyTorch UBC Yankai Group
4 PEFT Methods Evaluated
4 Benchmarks Sequential Vision Tasks

Authors: Muhammad Ahmad, Jingjing Zheng, Yankai Cao (University of British Columbia).

Developed in collaboration with a PhD student, this research paper investigates catastrophic forgetting in low-rank decomposition-based Parameter-Efficient Fine-Tuning (PEFT) methods under continual learning settings. It explores how constraining model updates to low-dimensional subspaces influences task interference and representation retention across sequential computer vision tasks.

Methodology & Experimental Setup
  • •
    Backbone Architectures: Evaluated on Vision Transformers (ViT-Base and ViT-Large) pretrained on ImageNet-1K.
  • •
    PEFT Strategies: Full Fine-Tuning benchmarked against four parameter-efficient methods: LoRA, PiSSA, LoRETTA, and WeGeFT.
  • •
    Sequential Benchmarks: Evaluated across CUB-200-2011, EuroSAT, Intel Image Classification, and Sports Image Classification via automated Python/Bash pipelines.
  • •
    Evaluation Metrics: Measured using Chaudhry's average forgetting metric, per-task accuracy, and final retention accuracy.
Key Theoretical & Empirical Findings
  • •
    Matrix Rank Trade-offs: Standard LoRA exhibits higher forgetting at small ranks due to forced shared directions; higher ranks steadily reduce task interference.
  • •
    Principal Subspace Interference: PiSSA causes acute forgetting at low ranks by directly perturbing principal singular vectors containing shared features.
  • •
    Structural Alignment & Tensor Benefits: Structurally aligned methods (WeGeFT) and tensor-train decompositions (LoRETTA) minimize forgetting with minimal parameter budgets.

Robotics & Control • C / C++

Two-Wheeled Self-Balancing Robot

ESP32 MPU-6050 IMU Kalman Filter PID Control NEMA 17 Steppers DRV8825 Drivers I2C
Kalman Sensor Fusion
High-Hz PID Equilibrium Loop

Engineered and programmed an inverted-pendulum self-balancing robotic platform powered by an ESP32 microcontroller. The robot achieves upright equilibrium by executing continuous real-time sensor fusion and high-frequency closed-loop PID motor corrections.

Sensor Fusion & Control Engineering
  • •
    Kalman Filtering: Implemented a 1D Kalman filter performing sensor fusion on raw accelerometer and gyroscope data from an MPU-6050 6-DOF IMU over I2C, eliminating drift and motor vibration noise for stable pitch angle tracking.
  • •
    PID Control Loop: Tuned a responsive Proportional-Integral-Derivative control algorithm to counteract dynamic tipping moments and maintain vertical center of gravity.
Actuation & Power Subsystem
  • •
    Stepper Drive: Dual high-torque NEMA 17 stepper motors paired with DRV8825 microstepping drivers for precision angular velocity control.
  • •
    Power Integrity: Isolated power rails with decoupling capacitors to prevent back-EMF spikes from affecting microcontroller operation.
